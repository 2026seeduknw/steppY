## 0. 세 줄 요약

1. **사용자가 실제로 하는 일**은 "지원 가능한지 확인 → 희망대학표(최대 25개) 작성 → 1/20 배정 결과 → 2차 서류·비자 → 출국 → 귀국 후 학점인정"이다. 앱의 단계도 이 순서와 날짜를 따라야 한다.
2. 지금 앱은 **IELTS를 받고, 지망을 3개까지만 받고, 여름·겨울학기를 교환 시기로 고를 수 있다** — 모두 책자 규칙과 다르다 (3장).
3. 학교 데이터는 **2027-1 원본**이다. 2027-2 명단이 **2026-12-15**에 나오면 다시 가져와야 한다.

## 2. 규칙 → 기능 매핑

### 2.1 지원 가능 판정 (학교 찾기 배지 · `js/components/eligibility.js`)

지금은 "학교 GPA 컷 ≥ / TOEFL 컷 ≥"만 본다. 책자 기준으로 판정 순서는:

1. **연세대 공통 자격** (학교와 무관)
   - 학부: 본교 2학기 이상 이수 (3학년 편입생 1학기), 전체 평량평균 **2.8/4.3** 이상
   - 대학원: 1학기 이상, 학·석(·박) 각 2.8 이상, 학점 이수 목적만
2. **연세대 TOEFL 최소** (계열별): 인문·사회 **79**, 자연·공학·예체능·의치간 **68**, 대학원 **100**
   → 학교 컷이 더 낮아도 이 값 아래면 지원 불가
3. **어학 성적 유효기간**: 2025-09-01 이후 응시. 일부 학교는 1년 이내
4. **학교별 조건**: GPA 컷, TOEFL 컷(+영역별 subscore), 지원 불가 학과, 이수학기(4학기 이상 등), 자국 국적 불가
5. 비영어권 학교: 그 언어 시험 등급 (아래 표)

판정에 필요한 사용자 정보 중 지금 안 받는 것: **학부/대학원, 계열, 이수 학기 수, 편입 여부, 어학 응시일, 국적**.

### 2.2 배정 점수 (아직 없음 — 만들 가치 큼)

실제 배정은 "컷 통과"가 아니라 **총점 석차 → 희망대학표 순서대로** 내려가는 방식이다.

| 전형 | 학점 | 어학 | 총점 |
|---|---|---|---|
| 영어권 | 백분위 × 2 (200) | TOEFL (120) | 320 |
| 비영어권 | 백분위 (100) | 환산 (40) | 140 |

- 어학 면제자: 어학 점수를 "만점 × 본인 CGPA 비율"로 환산 (책자 표현 그대로. 정확한 식은 국제처 확인 필요)
- 비영어권 환산표 (40점 만점):

| 언어 | 40 | 35 | 30 |
|---|---|---|---|
| 독일어 | Goethe B2 · FLEX 1000~1500 | Goethe B1 · FLEX 901~1000 | FLEX 800~900 |
| 러시아어 | TORFL 1급 · FLEX 1000~1500 | TORFL 기본 · FLEX 901~1000 | FLEX 800~900 |
| 스페인어 | DELE B2 · FLEX 1000~1500 | DELE B1 · FLEX 901~1000 | FLEX 800~900 |
| 프랑스어 | DELF B2 · FLEX 1000~1500 | DELF B1 · FLEX 901~1000 | FLEX 800~900 |
| 일본어 | JLPT N1 | N2 | — |
| 중국어 | HSK 6급 | 5급 | — |

→ "내 총점" 계산기 + 학교별 경쟁 정보(정원 `slot`, 과거 경쟁률이 생기면)를 붙이면 "배정 가능성"을 보여줄 수 있다. **4.3 학점 → 백분위 환산식은 책자에 없다** (84 = 2.8 하나만 나옴). 연세대 학칙 환산표 확보가 선행 과제.

### 2.3 희망대학표 (지망 · `js/state.js` wishlist, `js/saved.js`, `js/home.js`)

- **1~25개**, 순서 있음, 최종 1곳만 배정
- **한 전형(언어권)만**: 영어권과 비영어권을 섞을 수 없음. 한 학교에 영어·현지어 트랙이 둘 다 있어도 고른 전형 쪽만
- 학교마다 **지원 학과**를 골라야 함 (지원 불가 학과 = 배정 안 됨)
- 파견기간 '1'(한 학기·두 쿼터) / '2'(1년·세 쿼터) — 학교마다 가능 기간 다름
- 1-8 17:00 이후 변경 불가

### 2.4 학점 인정 (학점 인정 탭 · `js/credits.js`)

지금은 과목 매칭만 있다. 계산 규칙을 붙일 수 있다:

- **학기당 인정 한도** (학부): 1학기 = 졸업학점의 1/8, 1년 = 1/4 (5년제 건축 1/10, 1/5). 대학원 = 학기당 12학점
- **ECTS** = 총 이수 ECTS × 1/2, 올림 (예: 15 ECTS → 7.5 → 8학점). Fail 과목 빼고
- **쿼터제** = 취득 학점의 2/3
- 과목 대체 조건: 내용 유사 + 파견교 학점 ≥ 본교 학점 (두 과목 합산 가능). **파견교 1과목 → 본교 2과목 불가**. 남는 학점은 일반선택
- 본인 입학년도 이후 개설 과목만 (대학원은 제한 없음)
- 전공은 유사 과목이 없어도 학과장 확인으로 전공선택 인정 가능
- 본교에서 이미 들은 과목은 대체 불가 (일반선택만)
- 자격증용 과목(영양사·CPA 등)은 대체인정 받지 말 것 — 성적표에 과목명이 안 남음
- 승인 주체: 전공 = 담당교수+학과장, 학부대학 = 담당교수+학부대학장, 일반선택 = 학사지원팀, UIC CC = 담당교수+CC책임교수

→ "학점 시뮬레이터": 파견 기간·학교 학점제(학기/쿼터/ECTS)·듣고 싶은 과목 → 예상 인정 학점과 한도 초과 여부.

## 4. 데이터에 필요한 것

**사용자 프로필에 추가**
- 학부/대학원(석·박·특수), 계열 (TOEFL 최소 판정용)
- 이수 학기 수 (파견 학기 기준이 아니라 **지원 시점** 기준), 편입 여부·학년
- 어학 시험: 종류 + 점수 **또는 등급** + **응시일**, 면제 여부
- 지원 전형: 영어권 / 비영어권(언어)
- 파견 기간: 1학기 / 1년 (지금 `exchangeTerm.unit` semester/quarter 있음 — 학교 학제와 별개로 "신청 기간"을 둬야 함)
- 국적 (자국 파견 불가 학교, 국적 제한 장학금)
- 배정 결과 (1-20 이후)

**학교 데이터에 있어야 할 것** (2027-2 명단에서 확인)
- 언어권별 트랙 (한 학교에 여러 개 가능), TOEFL 총점 + subscore 컷, 비영어 등급
- 지원 가능/불가 학과, 필요 이수학기, 자국민 불가 여부, 어학 유효기간(1년/2년)
- 가능 파견기간 (1학기/1년만), 학제 (학기/쿼터/ECTS/기타)
- 교류활성화 대상 여부, 숙식비 지원 여부

**학기별 일정 테이블** (신규) — 1장의 날짜들을 학기별 행으로. 코드에 날짜를 박지 않는다.

## 5. 문구·UX에서 꼭 지킬 것

- **"지원 가능"은 "합격"이 아니다.** 배정은 석차 순이고, 배정돼도 최종 입학은 파견교가 결정. 배지 문구가 보장처럼 읽히면 안 됨
- **배정 후 취소 = 영구 재지원 불가 + 봉사 의무**. 취소·지망 관련 화면엔 이 경고를 숨기지 말 것
- **비자는 학생 본인 책임** (국제처 대행 안 함). 비자 목록은 "참고, 공식 출처 확인"
- **등록금 미납·휴학 = 미등록 제적**. 파견 중에도 등록금 알림은 강하게
- 영문 이름은 **여권과 철자·띄어쓰기·하이픈까지 동일**해야 함 — 프로필에 영문명 받으면 이 안내
- 비영어권 파견자는 **수업 과반을 현지어로** 들어야 함 — 비영어권 선택 시 안내
- UC 계열: 캠퍼스는 UCEAP가 정하고 바꿀 수 없음 — UC 상세에 경고
