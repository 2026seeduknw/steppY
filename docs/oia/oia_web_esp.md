## 2. 책자에 없던 것

- **프로그램 종류**: 국제처 학기 파견은 교환학생(ESP), 방문학생(VSP), **GLOBAL STERN** 셋. 모두 학점 인정. (GLOBAL STERN 내용은 이 페이지에 없음)
- **지원 시기 규칙**: 출국 약 **8개월 전** 연세포탈로 지원. **봄학기 파견 = 전년도 7월 초, 가을학기 파견 = 같은 해 1월 초.** 정확한 날짜는 매 학기 [Outbound 공지사항(m04_01)](https://oia.yonsei.ac.kr/outbound.php?mid=m04_01).
  → 봄 파견 학기 일정이 없을 때 앱이 "대략 언제쯤"을 안내하는 근거로 쓸 수 있다.
- **배정가능 대학 확인처**: Outbound 공지사항 + [OIA University Finder](https://oiaunivfinder.netlify.app/) (국제처가 운영하는 학교 검색).
- **ESP 등록금**: 교환 협정에 따라 **파견교 등록금 면제**를 명시. 숙식·생활비·보험료는 파견교 기준으로 본인 부담.
- **VSP**: 기간 연장 불가 명시. VSP 장학금(연세대 등록금 80%)은 **연세대 재학생만** — 연세대로 오는 외국인 방문학생은 해당 없음. 교내 타 장학금과 중복 불가.
- **비자**: 연속 파견이면 프로그램마다 비자 종류가 다를 수 있음. 필요 서류는 해당국 대사관 홈페이지에서 직접 확인.
- **안내책자 원본 폴더**: [Google Drive](https://drive.google.com/drive/folders/1qbQGqZ5Niv6nEhqMsa45Q40Rjhm_hlqB?usp=sharing) — 새 학기 책자가 올라오는 곳.

## 3. 책자와 같은 내용 (요약 문서 참조)

| 홈페이지 항목 | 책자 요약 |
|---|---|
| ESP/VSP 비교표 (대상·기간·등록금·파견교·학점 인정) | 3장 |
| 복수 파견 — 재학 중 최대 1년, ESP 1회, VSP 1학기, 조합표 | 3장 |
| 정규학기 안에서만, 최종학기는 본교, 마지막 학기 파견은 한 학기 + 초과학기 서약서 | 2장·5장 |
| 파견 중 휴학 불가, 휴학 중 선발되면 파견 학기 복학·등록금 | 8장·9장 |
| 학생 유형별 파견 시기 (학부·의치예 4학기·편입·복수전공·대학원) | 5장 |
| 쿼터제 (두 쿼터 = 한 학기, 한 쿼터만이면 불인정), UC(UCEAP 배정), 남반구 | 5장 |
| 지원 전 유의사항 5가지 (전형 중복 불가 등) | 2장 |
