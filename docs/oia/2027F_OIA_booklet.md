## 2. 지원 전 필수 유의사항

1. 영어권·비영어권 **중복 지원 불가** — 하나만 선택.
2. 정규학기 안에서만 파견, 최종학기는 연세대에서. 마지막 정규학기(8학기 / 건축 5년제 10학기) 파견은 한 학기만, 출국 전 초과학기 서약서 제출.
3. 배정 후 **대학 변경 불가**. 배정 후 취소하면 패널티 + 이후 정규학기 국제처 파견 **영구 재지원 불가**. (홈페이지는 '모든 종류의' 국제처 파견 — [oia_web_esp.md](oia_web_esp.md))
4. 배정 ≠ 입학허가. 최종 입학은 파견대학이 결정.
5. 비자·Residence/Study Permit은 학생 본인 책임 (국제처 대행 없음).

## 3. 프로그램 비교

| | 교환학생 ESP | 방문학생 VSP |
|---|---|---|
| 등록금 | 연세대에만 | 연세대 + 파견대 둘 다 (VSP 장학금 = 연세대 등록금 80%, 교내 타 장학금과 중복 불가) |
| 학기·학점 인정 | 인정 | 인정 |
| 기간 | 1~2학기 | 1학기만 |
| 대학 | 교환협정 대학 | SAF Korea 회원교 |
| 대상 | 학부생·대학원생 | 학부생만 (의·치·간, 대학원생 불가. 미래캠은 별도 문의) |

- 학위 취득 불가. 숙식비·생활비·보험료는 본인 부담.
- 교환 인원은 학교 간 균형 때문에 매 학기 변동.

### 복수 파견 (재학 중 총 최대 1년 = 2학기)
- 정규학기 ESP는 **1회만**. 1년 원하면 처음부터 1년으로 신청.
- VSP 최대 1학기. 하계·동계 프로그램 1회만.

| 조합 | 가능 |
|---|---|
| ESP 1학기 + ESP 1학기 | 불가 |
| ESP 1학기 + 하계·동계 1회 | 가능 |
| ESP 1년 + 하계·동계 1회 | 조건부 (국제처 협의) |
| ESP + 하계·동계 2회 | 불가 |
| VSP 1학기 + ESP 1학기 | 가능 |
| VSP 1학기 + VSP 1학기 | 불가 |
| ESP 1학기 + VSP 1학기 + 하계·동계 1회 | 가능 |

## 4. 지원 자격

### 이수학기·학점 (온라인 지원서 작성 시점 기준)
| | 이수학기 | 학점 |
|---|---|---|
| 학부생 | 본교 2학기 이상 (3학년 편입생 1학기) | 전체 평량평균 2.8/4.3 (백분위 84) 이상. 편입생은 전적대도 2.8 이상 |
| 대학원생 | 본교 1학기 이상 | 석사: 학·석사 각 2.8. 박사: 학·석·박 각 2.8. 학점 이수 목적만 (박사는 coursework 마쳤거나 연구·자료수집 목적이면 불가) |

- 일부 파견대학은 4학기 이상 이수 요구 → 대학 명단 확인.
- 지원 중 듣는 계절학기는 평량평균에 미반영 (2027-2 지원자는 2026 겨울 계절학기 미반영, 2026-2학기까지만).
- 국적은 안 봄. 단, 자국 국적 학생을 안 받는 대학 있음 → 명단 '기타 자격조건'.

### 어학 — 영어권 (TOEFL iBT, 120점 만점)
| 계열 | 최소 점수 |
|---|---|
| 인문·사회 | 79 |
| 자연·공학·예체능·의치간 | 68 |
| 대학원 | 100 |

- IELTS, TOEFL Home Edition, TOEFL IPT, Duolingo English Test, TOEFL Best Score **불가**.
- 2026-01-21 TOEFL 개정: 총점(120) 기준은 2년간 유지. 영역별 subscore는 30점 → 6점 체계로 바뀜. 개정 전 성적표는 그대로 제출. 대학별 subscore 요건 확인.
- 수업 언어가 영어면 영어권. 대학이 여러 언어 제공하면 하나만 골라 지원.

### 어학 — 비영어권 (6개 언어, 환산 40점 만점)
독일어·러시아어·스페인어·프랑스어·일본어·중국어. 어학증명서 사전 제출 기간에 내지 않으면 비영어권 지원 불가.

| 언어 | 40점 | 35점 | 30점 |
|---|---|---|---|
| 독일어 | Goethe B2 / FLEX 1000~1500 | Goethe B1 / FLEX 901~1000 | FLEX 800~900 |
| 러시아어 | TORFL 1급 / FLEX 1000~1500 | TORFL 기본 / FLEX 901~1000 | FLEX 800~900 |
| 스페인어 | DELE B2 / FLEX 1000~1500 | DELE B1 / FLEX 901~1000 | FLEX 800~900 |
| 프랑스어 | DELF B2 / FLEX 1000~1500 | DELF B1 / FLEX 901~1000 | FLEX 800~900 |
| 일본어 | JLPT N1 | JLPT N2 | |
| 중국어 | HSK 6급 | HSK 5급 | |

- DELF Junior 불가. 유효기간 없는 JLPT·DELF는 파견대학이 제한 없을 때만.
- 비영어권 파견자는 파견대학에서 **과반수 강의를 해당 언어로** 들어야 함. 대부분 영어 강의면 영어권으로 지원.
- 언어권별 따로 경쟁.

### 어학증명서 공통
- 파견 시작일 기준 2년 이내 → 2027-2 파견은 **2025-09-01 이후 응시**분만. 일부 대학은 1년 이내 요구.

### 어학 면제
- 영어: 모국어(미국·캐나다(퀘벡 제외)·영국·아일랜드·호주·뉴질랜드) 또는 입학 전 영어로 초·중등 12년 이수.
- 비영어: 해당 언어 모국어 또는 그 언어로 12년 이수.
- 면제 승인 시 어학 점수는 만점 기준으로 **본인 CGPA에 비례해 환산**. 기간 지나면 접수 불가.

### 학생 유형별
- 편입생: 전적대 성적표 제출. 편입 때 인정받은 학점도 학점인정 한도에 포함되니 남은 한도 확인.
- 졸업예정자 복수전공생: 복수전공 진입 후 1학기 이상 수료 후 휴학한 자. 진입 전·후 평량평균 각각 2.8 이상 (합산 안 함). 이미 교환/방문 다녀왔으면 불가.

## 5. 파견 시기·기간

- 학부생: 1학기 또는 1년. 의예·치의예 4학기는 진급심사 전 학점인정 못 하면 파견 후 1학기 휴학 동의 조건.
- 2학년 편입생: 본교 2학기 이상 후 지원, 3학년 2학기부터. 3학년 편입생: 1학기 이상 후 지원, 4학년 1학기부터.
- 졸업예정자 복수전공생: 진입 후 첫 학기 수료 → 두 번째 학기 휴학하고 준비 → 그 기간 중 한 학기 파견.
- 캠퍼스 내 복수·다중전공자: 단일전공과 같이 8학기까지.
- 석사(4학기제): 3 또는 4학기 중 한 학기만. 박사: 한 학기만, coursework 기간·완료 전에만. 5학기제 특수대학원: 3학기부터 한 학기, 소속 대학원 사전 승인.
- **쿼터제**: 1년만 가능한 쿼터제 대학에서 단축하면 두 쿼터 수료해야 한 학기 인정. 한 쿼터만이면 학점·학기 모두 불인정.
- 남반구(호주·뉴질랜드)는 봄·가을학기가 반대.
- **UC 계열**: 봄 파견은 1학기 또는 1년, 가을 파견은 1년만. 2차 서류에서 캠퍼스 3곳 지망, UCEAP가 최종 결정(지망 외 배정 가능). 캠퍼스 이유로 변경·취소 불가.

## 6. 지원서 작성

- 경로: 연세포탈 → 학사정보시스템 → 학사행정 → 국제학생교류 → (국제처)해외파견프로그램신청
- **여권 영문 성명**으로 작성. 모든 서류의 영문 이름이 철자·띄어쓰기·하이픈까지 동일해야 함.
- 대학별 지원학과 선택 필수. 지원 불가 학과 쓰면 배정 안 됨.
- **희망교환대학표: 최소 1개 ~ 최대 25개**, 지원한 언어권 대학만. 최종 1곳 배정.
- 파견기간 '1' = 한 학기 또는 두 쿼터, '2' = 두 학기 또는 세 쿼터(1년).
- 전공 없으면 유사 전공 지원 가능 (경영→경제, 법→범죄학, 수학→응용통계) — 원전공자보다 불리.
- 일반적으로 해당 전공 과목 4개 이상 들었으면 그 전공으로 파견 가능하다고 봄. 선수과목은 미리 이수 권장.
- 지원 기간 이후 희망 대학·기간 변경 불가.
- 비영어권 전형 지원자에게 선발 우선권.

## 8. 파견 전 준비

- 입학허가서 직접 받으면 국제처에 사본 제출.
- 여권은 1차 지원 전에 미리 발급 (2차 서류에서 대부분 요구). 만료일 확인.
- 비자는 입학허가서 받은 뒤 주한 대사관/영사관에 직접.
- 등록금: 본교 납부 기간에 내고 재학 유지. 미납·휴학 시 **미등록 제적**. 직전 학기 휴학했으면 파견 학기 복학 신청 필수. 출국 후여도 기간 맞춰 처리하면 됨.
- 숙식비 지원 대학 (ISEP, Washington College, Keio, Amherst 등): 기숙사비(SK국제학사 2인실 기준)·식비(1식 6,500원 기준)를 국제처에 내고 현지에서 제공. ISEP는 Placement fee 별도(환불 불가).
- 출국 1주일 전: 출국신고서 + 여행자보험 증서 (+마지막 학기 파견자는 초과학기 서약서).

## 9. 파견 중

- 파견 중 휴학 불가.
- 파견 기간 중간의 본교 계절학기 수강 불가 (전후는 가능).
- 해외 계절학기 학점 받는 두 방법 (교환·방문·유학 합쳐 해외 수학 최대 1년):
  1. 교무처 학사지원팀 '유학생' 사전 승인 — 같은 파견대학이면 개시 2개월 전 신청 시 최대 인정 학점 + 7학점 추가. 다른 대학이면 사전 승인 없으면 불인정. (yshaksa@yonsei.ac.kr)
  2. 국제처 여름·겨울학기 해외파견 프로그램 — 최대 7학점, 매년 2~3월·9월 모집. (02-2123-4703 / studyabroad@yonsei.ac.kr)

## 10. 귀국 후 — 학점인정

체크리스트: ① 귀국신고 + 경험보고서 ② 파견교 공식 성적표 제출 ③ 학점인정 신청. 이수 학점이 없어도 절차는 꼭 진행.

### 학부생
- 순서: 귀국신고·경험보고서 완료 → 국제처가 총 취득학점 환산 입력 → 학생이 학사정보시스템 → 성적 → 인정학점 → 교류학생학점인정(국제처)에서 요청서 + 수강편람/강의계획서 업로드.
- **최대 인정 학점**: 1학기 = 졸업학점의 1/8, 1년 = 1/4 (건축 5년제는 1/10, 1/5). 쿼터제는 취득 학점의 2/3만. 소수점 올림.
- 파견대 졸업학점으로 인정되는 것만. 성적표상 학점 0, F, Non-Pass, 수강취소 과목 제외. ESL은 공식 성적표에 학점 있으면 인정.
- 과목 대체 인정: 전공 = 담당교수 검토 + 학과장 승인, 학부대학 과목 = 담당교수 + 학부대학장, 일반선택 = 학사지원팀. UIC CC과목 = 담당교수 + CC책임교수.
- 대체 조건: 내용 거의 유사 + 파견대 학점 ≥ 본교 학점. 두 과목 합쳐서 본교 학점 이상이면 가능. **파견대 1과목을 본교 2과목으로 인정 불가**.
  - 예: English 3학점 → UA121(3) 대체. English(1) 2 + (2) 2 → UA121 대체 + 1학점 일반선택. English Writing 2 → 대체 불가, 2학점 일반선택. English(1) 6 → 1과목(3)만 대체, 3학점 일반선택.
- 본인 입학년도 이후 실제 개설된 과목만 대체 가능.
- 전공은 본교에 유사 과목 없어도 학과장 확인으로 전공선택 인정 가능.
- 완료 후 변경·추가 불가. 파견 학점은 평량평균 미포함, 성적표엔 파견학기 수·총 인정학점·기간·대학명만.
- 본교에서 이미 들은 과목을 다시 들으면 재수강 처리 안 되고 일반선택만.
- 성적증명서로 이수 증명이 필요한 과목(식품영양사, CPA 등)은 대체인정 받지 말고 본교에서 이수.

### ECTS (유럽)
- 총 취득 ECTS × 1/2, 올림. 예: 20 ECTS 신청 중 5 ECTS Fail → 15 × 1/2 = 7.5 → **8학점**.
- 과목별 올림 가능하나 합계가 전체 환산 학점을 넘을 수 없음.
- MSU credit, UK credit 등은 별도 공식 → 대학 Factsheet 확인.

### 일반대학원생
- 모두 전공 교과목으로 과목 인정. 입학연도 제한 없음, 같은 학정번호면 최근 개설분 선택.
- 파견 학기당 최대 12학점. 수료이수학점으로 반영.
- 경로: 학사정보시스템 → 성적 → 학점인정신청(해외교환, 유학) → [추가]→[돋보기]로 과목 선택, 구분 Z2 확인. 진행 중 신청은 취소 불가.

## 12. FAQ 요점

- 파견 직전 학기 휴학 가능, 파견 학기엔 복학 필수. 이메일 주기적 확인.
- 외국인 지원 가능, 단 출신국 파견은 거절될 수 있음.
- 기관파견: ISEP, GE3 — 하나의 군으로 배정 후 2차 서류 때 회원교 중 선택.
- 학교 선택: 목표 → 입학 기준·개설 과목·위치·분위기. 학사포탈 경험보고서 참고. 랭킹만 보지 말 것.
- 학점인정 100% 보장 아님 — 필수 과목은 가급적 본교에서.
- 비용(교환): 본교 등록금 + 파견대에 기숙사·식비·예치금·학생회비·외국인학생 서비스비·보험료.
- 졸업예정자 복수전공생 ≠ 일반 복수전공생.
